# Rapid_ART_ABM
This project contains Agent-Based Model for assessing introduction of rapid ART for HIV care in Japan, comparing to current situation of 1-month delay and 2-months delay.
Code includes, but not limited to Budget impact analysis, and Cost-Effective analysis using this micro-simulation model.
